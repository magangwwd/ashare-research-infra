# ETF 项目自主研发与 GPT 决策机制

> 状态：研究系统已通过一次 GitHub 真实全链路运行；历史数字与前瞻能力严格区分。
> 研发范围：8 只固定 ETF；每次至多持有一只 ETF，也可以空仓；最大**历史**回撤数值目标 25%，并非对未来的保证；绝不接券商或自动下单。

## 责任与接续

- **GitHub Actions** 执行固定、可重现的任务流水线，不需要用户电脑开机，也不需要 GPT 持续在线。一次运行按 `research_pipeline.py` 编排执行，阶段完成立即开始下一步；成功后停止，不按小时重跑整个研究项目。
- **GPT 主动事件巡检** 负责判断新成果/阻塞、选择下一项研究、在授权范围内改进代码和触发**一次**必要的验证。条件巡检最多按小时检查一次，但**不是 GitHub 的每小时回测**，也不能保证实时触发；若没有新事件，应停止、保持安静。
- **GPT 每天北京时间08:00正式审核**：提供当日已核验证据、尚存数据缺口、代码及数据版本、下一阶段安排。用户随时提出新要求，GPT 可立即参与。
- **无人值守的任务推进限制**：GitHub 无法自行构想新的策略算法；未经事先编码的下一项研究须由 GPT 在检查轮次开发并写入仓库。绝不虚报无限制全天自主学习。

## 已写入代码的研究链

1. 获取8只基金的 Tushare 价格和交易日历；严格禁止凭空填充行情。
2. 审计上市日、交易日缺口、重复记录、复权因子覆盖，未能确认缺口真实原因就标记 REVIEW_REQUIRED。
3. 回归测试，包括会计守恒、检查点恢复、500 异常处理、不可交易标记等。
4. 旧月度策略基线、12种探索性候选结果（仅作为旧研究对照）。
5. 识别隐含每日再平衡带来的成本偏差。
6. 查询 Tushare 短区间复核缺口，但同一数据源重查不能证明停牌。
7. 逐日现金与持有 ETF 份额的独立自融资模拟，以及可执行滚动历史回测。
8. 固定候选的交易成本压力测试，每边0.1%、0.3%、0.5%。
9. **新增**同区间独立策略基准：沪深300 ETF（510300.SH）、黄金 ETF（518880.SH）的真实开盘买入并持有，以及0%利息现金；**仅作为对照，不等于独立行情供应商校验**。
10. 研究验收门禁：固定8 ETF与全部输出签名、历史回撤指标、缺口/分红/事后调参/前瞻证据。策略一律 NOT_FOR_TRADING。
11. 结果和检查点传入 GitHub Artifact；成功研究产物增量上传 Google Drive。

## 中断、故障、检查点

- `state/run_checkpoint.json` 保存任务状态、实际 GitHub run、研究分支 SHA、所需产物SHA256、失败和重试记录；`state/drive_upload_checkpoint.json` 保存每个文件上传成功证据。
- GitHub Runner 超时/失败后使用 Artifact 作为恢复候选；只有研究代码 SHA 相同、已完成产物完整且 SHA256 校验通过才可跳过已有步骤。
- 有限自动重试（下载、云盘上传等），绝不无限重跑；本次执行失败后可以由授权 GPT 轮次审核、修复并安全启动新一轮验证。
- 上传时出现 HTTP 500 先指数退避重试，已确认成功的文件在同一检查点恢复时不重复上传。GitHub Artifact 不是永久存储，保留期和 Drive 上传应按日志复核。
- 严重数据疑点、真实分红/复权冲突、未经检验的策略调整均标记人工研究审核，阻止发布实盘结论。
