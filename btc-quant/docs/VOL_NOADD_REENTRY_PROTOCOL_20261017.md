# BTC 深回撤禁加仓 × 有条件恢复：独立消融试验（研究协议）

## 不修改的基准与执行

使用现有Binance BTCUSDT 1D、已验证数据截至2026-10-16 UTC；研究测试期2022-06-29至2026-10-16，730日先行训练观察 / 90日分折（18折），前180日热身。冻结V3原代码、前向账本及A股任务不动。1000 USDT现货账户不杠杆，BTC最高目标仓位50%，上一完整UTC日收盘发信号、下一日**历史模拟**开盘成交。单边费滑0.15%与0.30%，跨折资金、持币数量、风险状态和高水位不重置。15%账户级永久停机规则不修改，不保证日线止损不超出15%。

要求本实验先与上一轮`vol_risk_study.py`程序对`VOL_BASE`和`VOL_DD5`的每日净值、交易记录分别进行1x/2x**完全复现**，否则主回测失败。

## 试验变体

- `VOL_BASE`：原纯波动控制。
- `VOL_DD5`：原5%净值回撤软保护，每次新的日线开盘减仓BTC占比至25%，回撤<=3%且周一才能清除软保护。
- `VOL_NOADD_REDUCED`：全局`REDUCED`且上个UTC已完成收盘相对历史高水位回撤≥8%时，周一调仓**禁止新增BTC**，原止损、卖出和全局恢复不变。
- `VOL_DD5_NOADD`：软保护＋上述无条件禁加仓，检验是否多余。
- `VOL_DD5_STAGE_RECOVERY`：软保护状态持续存在，改为最近已完成收盘价高于60日均线、30日涨幅为正、20日/60日年化波动率比≤1.40的周一确认为“良性恢复”。连续2个合格周一把**软保护目标仓位上限**由25%提至35%，连续4个提至50%；任一不合格周一恢复25%。全局8/4/15保护仍独立生效、软保护标记不清除。
- `VOL_NOADD_STAGE_RECOVERY`：前一个软恢复＋深回撤禁买；只有阶段1/2确认后可以重新增仓，否则禁买。
- `VOL_NOADD_GLOBAL_REENTRY`：高风险额外对照！无软保护，连续2/4个符合上述确认的周一，将仍处REDUCED状态的目标乘数从0.50依次放宽到0.75、1.00，始终限25%绝对仓位，不清除全球`REDUCED`标记或15%永久停机条件。
- `VOL_DD5_GLOBAL_REENTRY`：软保护分阶段恢复＋同一全局REDUCED目标放宽，进行反例检验。

以上阈值是本轮研究选择，历史2022—2026走势已为研究者所知，**不构成真正事前外样本**，只能称回顾性消融验证，不能声称前向有效。新增策略参数未经统计选优与正式批准。

## 原先声明的两轴研究门槛

须在1x与2x成本均保留原VOL_BASE至少85%累计净收益，且最大回撤相对下降至少25%。只是研究筛选门槛，满足也不能直接授权实盘。
