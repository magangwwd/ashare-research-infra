## V3 策略和风控（研究参数已批准，非最优性声明）

- 收益趋势：30/90/180日回报为正的个数除以3；BTC基础仓位 = 趋势强度 × min(50%, 10% / 最近60日对数日收益年化波动率)。波动率为零或无效保持USDT现金。
- 只持有BTC与USDT现货，最大正常目标BTC权重50%；余额USDT；无杠杆、无卖空。
- **周一北京时间08:00**，依据上一日已经结束的UTC日线更新基础目标；普通调仓只有实际占比与风险调整后目标相差至少5个百分点才触发；**目标为零则无条件清仓尾仓**。
- **NORMAL→REDUCED**：上一UTC日收盘的账户净值相对历史高水位回撤≥8%，下一次建模开盘执行一次必要减仓；目标基础权重减半，且≤25%。后续不每日机械反复追单。
- **REDUCED→NORMAL**：只在周一北京时间08:00，且前一已完结UTC日收盘回撤≤4%；实际调仓仍受趋势/波动和5个百分点门槛约束。
- **任意状态→HALTED**：上一已完结UTC日收盘回撤≥15%，下一个建模开盘清仓，冻结账本内永久停止新买入；历史高水位不重置。日线监测及跳空意味着15%**不是**最大回撤保证。
- 初始虚拟资金1000 USDT；单边手续费0.10%+模拟滑点0.05%，现金不计利息。
- 参数只允许在本次12周结束后的新策略版本中修改；观察期内维护基础设施可修复，但须记录代码提交和行为变更，不能偷换策略。

## 前向运行边界与真实限制

- 正式**前向观察日**：2026-10-15 至 2027-01-06（UTC完整日）；**8周中期核查**：约2026-12-10；**12周总结**：2027-01-07以后。

- 默认每日 `02:41 UTC`（北京时间10:41），GitHub Actions 定时执行：`.github/workflows/btc-v3-forward.yml`。GitHub cron可能延迟。该作业必须先获取并校验**已经完整收盘的UTC日线**，再使用 GitHub Drive 中上一次可信状态，仅推进一个新UTC日，并创建一份不可覆盖的当日状态记录。没有新日线则幂等不做事；漏日、源数据变化、重放、代码哈希/Drive失败则拒绝继续，保留故障证据。
- **关键诚实限定**：目前为 `EOD shadow paper`（收盘后按当日日线开盘价进行**假设成交的前向影子账本**），不是在周一08:00实时收到交易所报价后执行的模拟订单；因此不能验证成交延迟、挂单成交概率、OKX滑点，也不能声称已运行真实时点纸面撮合。前向观测可以检验规则稳定性、数据完整性、漏日保护和风险状态变更，但开盘模拟价格可能过于乐观。之后若要升级到严格实时模拟，必须经独立讨论，不得悄然改变冻结规则。
