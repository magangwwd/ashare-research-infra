## 2. 修改内容（固定30/90/180天趋势和10%波动目标）

1. 60日年化波动率严格采用每日**对数收益率**的样本标准差×√365；零/无效波动率保持现金，不再默认为50%。
2. 周一北京时间08:00（UTC周一00:00），使用**上一日已完成**的收盘信号，次日/当日周一开盘模拟成交；非周一不执行普通5个百分点调仓。
3. 目标仓位**精确为零时彻底清仓**，不能遗留小于5个百分点的BTC尾仓。
4. 8%账户回撤：下一开盘仅做一次紧急降风险卖出，此后不逐日追踪半仓目标；普通调整仍在周一进行。15%回撤触发永久停机，下一开盘清仓；每日收盘才发现风险时可能突破15%。
5. **新增、尚待正式审批的实现参数**：降风险状态仅在某个周一、且前一日收盘回撤已收窄到**4%或以下**时恢复正常。这是去抖动方案，而非原先冻结的V3指标，正式前向模拟前必须明确批准或替换。没有重置账户历史净值高水位（HWM）。
6. V1/V2仍是研究性简化重建，不能当作前两轮原版源码。

## 4. 风险匹配的初步研究性对照

为了避免直接将高敞口纯波动策略与低敞口V3相比，这里取**均不启用账户8%/15%保护的诊断版**，并将纯波动诊断账户与零收益USDT现金做静态组合。

- **仅以2020-01-01~2023-12-31**的已观察历史日收益波动率拟合现金/纯波动子账户的比例（非未来信息）：纯波动账户权重 **69.13%**，现金 **30.87%**；校准期组合年化波动与 V3 诊断版均约 **7.57%**。
- 在完整 **2020-01-01~2026-09-30** 的**回顾性**样本中：V3诊断版年化 **8.06%**、实际年化波动约 **7.55%**、最大回撤 **11.34%**；风险匹配纯波动+现金组合年化 **7.32%**、实际年化波动约 **8.07%**、最大回撤 **15.23%**。
- 风险匹配校准期并不能保证检验期完全同风险；此对照是风险贡献诊断，**不是独立样本外验证**。2026年数据早已被观察，不能再作为未使用的独立样本外。
- 不应使用账户永久停机版本进行趋势有效性主对照，否则停机时间差异会混入结果。

## 6. 验收结论

**候选有效，但尚未验收合格。** 应先由研究方案确认8%后的恢复阈值，再正式冻结本轮实现；继续做交易成本/流动性/异常日期审计及独立未来前向模拟。本次单次日线历史盈利无法证明稳定实盘获利。
