# BTC 波动率仓位策略：降回撤、尽量保留收益（2026-10-17 预登记）

## 研究目的与不可越界事项

已有实际回测（2022-06-29—2026-10-15，18 个滚动折，1,000 USDT，扣成本）：

| 基线 | 1×累计净收益 | 最大回撤 | 2×累计净收益 |
|---|---:|---:|---:|
| VOL_STATIC（无趋势投票的纯波动控制） | +51.11% | 13.38% | +50.70% |
| V3_STATIC（趋势投票 + 波动控制） | +29.68% | 8.03% | +28.50% |

首先排除“增加复杂规则总会更好”的预设。**只允许研究候选，不提升实盘或前向信号。** 不改 `btc-quant/backtest/run.py`、`config/v3_daily_frozen_20261015.json`、冻结提交与原前向账本；不干扰股票数据任务。复用现有私有配置与 GitHub Actions 运行环境，只用无交易密钥的 Binance Spot BTCUSDT 官方原始完整 UTC 1D，数据原件与结果仍保存既有 Drive 根 `BTC_Quant_System_OKX`（文件夹ID `1f1QpjccD0YvciS7RwaxfRGkuW-o0k_0P`），不新建文件夹，不覆盖结果。

## 必须完整复现的相同实验条件

- 真实日线原件/校验 SHA256；尚未发布的昨天 ZIP 标记来源滞后，只做截止已发布日期的历史测试，不生成可交易下一期开盘指令。
- 单一 USDT/BTC 资金账户，1000 USDT，现货仅做多，最多 50% BTC 仓位，不杠杆。收盘出信号，仅按**下一天历史日开盘价**模拟；费用与滑点单边0.15%、0.30%。这是 retrospective daily-bar proxy，不等于日内真实成交。
- 与上一阶段相同的18个（或数据更新后更多的）730训练观察日、90测试日相邻滚动折。回测净值、BTC数量、现金、风险标志、历史净值高水位**不在折间重置**。所有规则只使用当前决策前已完成的 K 线。
- 共享账户风险规则：前日完成收盘回撤≥8%先减半并拒绝本次加仓；周一北京时间08:00且收盘回撤≤4%才正常恢复；≥15%下个有报价开盘退出，且永不自动重启。跳空有可能造成回撤超15%，不宣称绝对保护。
- `VOL_BASE` 必须**与已在 GitHub 跑过的 `VOL_STATIC` 逐日净值和成交笔数一致**（1×、2×，误差低于1e-6 USDT），否则整个新研究报错，不生成结果。

## 预登记候选，不在历史测试后挑阈值

| 版本 | 条件和行为 | 为什么测 |
|---|---|---|
| VOL_BASE | 原纯波动；周一波动率目标=min(50%, 10%/60d年化波动率) | 唯一主基准 |
| VOL_CAP35 | 在原基准上限制最多35%仓位（正常周一调仓） | 检验少持币能否换来有价值的减回撤 |
| VOL_SCALE75 | 原目标仓位×0.75（周一调仓） | 固定缩小风险的消融 |
| VOL_SHOCK20 | 最近20d/60d年化波动率≥1.5时，在周一把原目标仓位减半 | 检验波动突变保护 |
| VOL_DD5 | 净值从高水位回撤≥5%后，下一有报价开盘将BTC占比压至25%以内；仅周一且回撤≤3%解除 | 检验比原8%账户总风险更早的保护；风险动作不得加仓 |
| VOL_COMBO | 同时实施 SHOCK20 与 DD5 | 检验叠加是否有利，避免先验认为越多越好 |
| VOL_TRAIN_RISK_MATCH | 每个90d折开头，仅凭前730d交易日的**近似、无交易费用**权重×日收益对照，估算V3 / VOL的年化波动率比，截断至0.30—1.0；下一90d使用该比例调低仓位 | 训练期定义的“风险配平尝试”。并非测试期已实现风险严格相等，不允许以此宣称风险匹配完成 |

R0/R1网格与衍生品因子均**不纳入**这组VOL专门实验，以免多变量混淆。基准V3仍采用上一阶段 `V3_STATIC` 同账本对照，同时冻结原V3前向程序不变。

## 事先声明的双轴验收门槛（不是实盘批准门槛）

判断某候选“在不显著牺牲收益下降风险”的**探索性**标准：
1. 在1×和2×成本下，都保留基准 `VOL_BASE` 至少 **85% 的正累计净收益**，且自身净收益为正；
2. 在1×和2×成本下，较对应基准的**最大回撤相对下降至少25%**；原13.38%则约要求≤10.04%（不是“降低25个百分点”）。
3. 无未来数据、交易成本错误、仓位/风险违规；脚本必须先证明与旧版VOL基准结果逐日一致。

报告也需要：各折净收益及回撤、成本、资金利用、最大持币比例、年化收益、波动率、Sharpe、Calmar、水下时长比例、最差月份近似值、风险保护事件明细。专门列出增量收益/回撤相对基准、与V3静态对照的差异，给出是否仅由降低平均仓位解释。再做每日前向、参数邻域和真正的外部时期验证，才可能考虑前向影子晋级；绝不以本次历史门槛自动判定有真实 alpha。
