## 提醒内容与真实持仓

新信号提醒：代码/名称、评分、下一交易日、限价、止损、止盈、三万元仓位上限、失效条件。无候选时明确说明，不强行选股。

持仓跟踪：模拟买入/卖出、持有天数、浮动净值、止损/止盈/40交易日退出、跌停或停牌受阻；同一事件不重复作为新提醒。当前只知道模拟持仓，用户未提供实际成交。真实持仓提醒必须以用户实际成交记录为准，不能把发送买入提醒视为已经买入。程序无券商接口。

## 相对旧代码的必要修正

1. 基底后3根脱离K线全部收盘才确认；从其下一根才允许回踩。
2. 供给区触碰/失效在选目标之前按当时历史判断；未知均线/状态不默认通过。
3. 每日top300按当日已经可得的过去20日成交额选取，不使用2015–2026整段未来均值。此为独立修正版，旧回测不能直接沿用。
4. 真实未复权价格用于费用、100股手数及模拟成交；形态用价格×当时复权因子，信号价格换回当前原始价。持仓发生公司行为时停账，待核验分红/股数再继续，禁止产生假收益。
5. 3仓资金按顺序分配、计最低佣金/卖出税费及每侧0.3%滑点。该费用是研究假设，不代表用户券商实际费率。未证明能成交时保守跳过；同根同时触发止盈止损按止损；跳空按更差价格；跌停即便超过5日也不能假成交。
6. 满仓新信号跳过；同日卖款不用于当天开仓。首轮从最新完整收盘启动，无追记历史前向成绩。
