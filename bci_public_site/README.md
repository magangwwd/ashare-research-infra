# 乳腺健康指南 · 简单互动版

公开首页：https://magangwwd.github.io/ashare-research-infra/

**面向普通患者及家属；只有一个中文版入口。**

## 最有用的五个入口

1. **我该怎么办？** 选“发现结节 / 检查异常 / 已确诊 / 康复”，展示根据 Google Drive 编辑资料整理的常见就医步骤和可以复制的医生沟通问题。
2. **全国医院怎么选？** 按地区、医院性质（包含军队医院）、诊疗方向及医院名称筛选；每家显示有出处的专科特点、适合先咨询的情况、官方就诊指引、医生资料及核查日期；最多比较两家医院。
3. **治疗方法通俗解释。** 用四步示意介绍检查评估、病理分型、治疗讨论、康复随访；最新疗法必须区分成熟临床应用与仍处于研究阶段的技术。
4. **医学词典。** 从云盘读取常见名词的中文白话解释，支持按词搜索和展开。
5. **最近研究。** 从云盘研究快照中展示限定数量的最新文献、康复、试验、监管和指南资料，由 `research_cn.js` 依据标题关键词保守生成中文主题提示。英文原标题仅折叠显示用于核实；**不将主题提示说成论文结论或疗效证据**。

## 页面风格

- 手机优先，默认内容简短，用按钮、筛选、卡片、折叠详情；先展现最重要内容，其他信息按需展开。
- 没有医疗专业人员版、技术 API 入口、病历上传、注册、在线问诊、自动诊断或隐藏的健康画像。
- 首页保留新发肿块、血性溢液、明显炎症等应当及时线下评估的提醒。
- 军队医院和其他信息不足的医院只显示证据等级及来源待核实状态，不能靠推断补齐科室、医生排班或号源。
- 医院公开介绍不是独立疗效排名。患者量、手术量、治愈率无可比资料时不显示。

## 数据与更新

`data/care-guide.json`：由 Google Drive 中文编辑文档 `BCI_public_care_navigation_v2_全国医院军队医院医生就医中文资料` 生成，验证每家医院/医生的出处、官方或第三方来源及查证日期。

`data/site-data.json`：GitHub Actions 从 Google Drive 最新真实医学研究归档里校验后生成的**公开题录元数据**（绝不公开内部研究摘要或患者身份信息）。

后台 GitHub Actions：
- `bci-drive-collector.yml`：约北京时间 07:30 采集公开来源并写入 Google Drive，确认上传后读取一致；
- `bci-pages.yml`：约 08:15 及每次成功采集后，从 Drive **读取最新有效数据**并重建网站；
- `bci-public-http-smoke.yml`：部署后从公网下载 HTML、JavaScript、两类公开 JSON，核查新版页面和来源数据。

GitHub 定时任务可能延迟。**网页重建不代表研究数据一定更新**；仅显示真实快照时间。医院编辑资料的有效性还依赖人工持续核对官方来源。

## 测试

`python -m unittest discover -s bci_public_site/tests -v`

`node --check bci_public_site/guide.js`

`node --check bci_public_site/research_cn.js`

敏感健康信息不应在网站输入，也不会主动收集。科普内容不是医疗建议；病理、检查和治疗应由执业医疗人员评估。
