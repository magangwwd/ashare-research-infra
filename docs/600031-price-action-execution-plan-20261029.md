三类新增事件：突破后回踩、上升结构中的回调、跌破后重新收回区间。实现前预登记关键区间算法、历史窗口、波动尺度/缓冲、候选条件、确认条件、等待上限、失败/超时、去重、失效与最早执行规则；保留全部候选及失败/超时案例。
周线背景、日线主结构、15分钟仅在覆盖合格时作触发研究；周线只用已完成数据，分钟量能对比历史同一时段；不插值成交数据，不把分钟缺口阻塞所有可做日线研究。
记录event_time、confirmed_at、earliest_execution_at；两右侧K线确认的高低点不得回填，收盘信号不假设已按该收盘价成交。关键位仅用当时信息。
复权特征按当时可得公司行为和一致口径构造；未复权真实价格用于成交，分红/送转单独入账；市场和行业归属按历史日期。缺数据仅阻塞依赖该数据的结论，记录降级原因。
