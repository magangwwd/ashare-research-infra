## 1. 因果数据、特征与有效性
- 按交易所日历排序；所有 `t` 的特征只用截至 `t` 已公布的日线和复权因子。完整周线只用上一个已结束的自然交易周，作为环境标签**不作筛选开关**。15分钟仅在该日应有的16根均齐、时间戳/量纲与历史同一时段可比时作辅助触发研究；否则 `minute_coverage=insufficient`，日线事件仍可研究，绝不插值。
- 以 `t` 时点已知的 `adj_factor` 将截至 `t` 的历史OHLC转为统一 `t` 价格尺度：`P_s^(t)=P_raw_s * factor_s/factor_t`（`s<=t`）。冻结候选的关键位与ATR也锁定在候选 `t` 尺度；以后 `u>t` 的观察价格用当日可得 `factor_u/factor_t` 转到同一尺度。缺失/冲突的复权、停牌、涨跌停或公司行为必须标 `data_blocked`，不悄悄使用未来因子；真实成交只用当日未复权报价。
- `TR_s=max(high_s-low_s, abs(high_s-prev_close_s), abs(low_s-prev_close_s))`，历史前收盘按同一 `t` 尺度构造；`ATR20_t` 为**截至t-1**连续20个有效交易日TR的算术平均（不含t）。任何一个所需日缺失则不可判定，ATR<=0也不可判定。价格比较统一容差 `1e-9`；阈值等号视为未越过，除非明确写 `>=`/`<=`。
- `H20_t=max(high_{t-20..t-1})`、`L20_t=min(low_{t-20..t-1})`、`H10_t=max(high_{t-10..t-1})`。均不含当日t；`SMA5_t/SMA20_t` 为截至t的5/20个有效收盘价均值；`SMA20_{t-5}` 为截至t-5的20日均值。历史不足20+5日不产出候选。若相邻日期/复权链不连续，不跨断点计算。
- `event_time`=首次满足候选条件的t收盘；`confirmed_at`=后续满足确认的那一日收盘；`earliest_execution_at`=确认后**下一合法交易日**，未确认则NA。确认/失效/超时不可回填到t。OHLC只能证明区间触及，不能证明同根触价顺序或订单成交。

## 2. 三种事件：候选→确认/失败/超时
每个候选固定**后续5个交易日**为等待窗口，包含第5日；逐日先判**失效/失败**，再判确认；同日既满足失败又满足确认，记 `ambiguous_same_bar` 并按失败保守处理，不删候选。所有事件保留候选日期、门槛、所用数据hash、等待状态和原因。

**PA2_A 突破后回踩**（关键位反应）：
- 候选：`close_t > H20_t + 0.25*ATR20_t`；记录固定 `level=H20_t`、`buffer=0.25*ATR20_t`。
- 确认：在t+1…t+5某日同时 `low_u <= level+buffer`、`high_u >= level-buffer`、`close_u >= level+buffer`；此时称“回踩并收复”，**不推断盘中成交先后**。
- 失败：在确认前任一日 `close_u < level-0.75*ATR20_t`；第5日仍无确认/失败则 `timeout`。

**PA2_B 上升结构中的回调**（趋势/回调修复）：
- 候选：`SMA5_t>SMA20_t>SMA20_{t-5}`，且`close_t<close_{t-1}`；`peak=H10_t`，`1.0*ATR20_t <= peak-close_t <= 3.0*ATR20_t`，`close_t>=SMA20_t-0.25*ATR20_t`；锁定候选当日 `SMA20_t`、`low_t` 和ATR。
- 确认：t+1…t+5某日 `close_u > high_{u-1}+0.25*ATR20_t` 且 `close_u>=SMA5_u`（后者仅使用u时已知数据）。
- 失败：`close_u < SMA20_t-0.75*ATR20_t` 或 `low_u < low_t-0.75*ATR20_t`；未确认/失败至第5日则 `timeout`。

**PA2_C 跌破后收回**（关键位/假跌破）：
- 候选：`close_t < L20_t-0.25*ATR20_t`；固定 `level=L20_t`、`buffer=0.25*ATR20_t`。
- 确认：t+1…t+5某日 `close_u > level+buffer`。
- 失败：确认前 `close_u < level-1.5*ATR20_t`；第5日仍未确认/失败则 `timeout`。

**缺口/去重**：等待窗口中任何必需数据缺失或复权不可信，候选记 `data_blocked` 并记录首次断点，不把它算失败或超时。每一类型同时最多一个活动候选；候选从t起至终态（确认/失败/超时/阻断）后，额外冷却**5个完整交易日**再允许同类型下一候选。不同类型同日允许并存，统计时保留全量并按交易日聚类，不按盈利结果挑选。记录候选总数、确认数、失败数、超时数、同根冲突数、阻断数、冷却排除数。
