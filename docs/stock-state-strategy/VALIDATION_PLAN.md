## 正式V1有效性结论的门槛

沿用 LOCK_TO_MARKUP_PAPER_STRATEGY.md 的原有标准，不缩短验证期：
- 至少30笔已平仓、至少12个月自然时间；信号均在正式激活后首次记录；无回填、无违规、无选择性漏记。
- 平均净R>0、利润因子>=1.2、扣费后组合收益>0、最大已平仓回撤不超过10%。
- 对相同入场且无派发退出的20日影子基准，日级净R增量为正且HAC p<0.05。
- 单独报告剔除最大盈利交易后的结果、年度/市场阶段差异和费用压力。

不能因为单元测试或短期盈利就提前认定有效。历史复核若已经失败，可以报告未通过并停止对应假设，不能承诺一定做出盈利策略。达到上述标准也只进入独立研究复核，不授权实盘。
