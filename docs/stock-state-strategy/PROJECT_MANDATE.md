- 本目录 backlog.json 为本专项唯一任务队列；不以聊天记忆代替仓库状态。
- 按用户2026-10-30补充指令，接入现有每天北京时间08:00“A股08:00数据晨检与决策”，不新增GPT定时任务，不改其他专项频率。晨检先验收上轮结果，再执行一项最高优先级任务；GitHub一次运行可连续完成预编排的确定性阶段。长期真实前向记录继续，不能因一次CI成功就结项。
- 当前未部署 GitHub 完工即时唤醒本会话的事件桥；本项目不新增外部 API 付费代理，也不把轮询称为事件触发。

## 明确允许和禁止

允许：读取相关 GitHub/Drive 证据，修改本专项代码与测试，创建隔离分支和草稿 PR，执行不交易的有界测试和研究，保存版本化证据，自主处理范围内的问题。
正式 V1 的策略文档与机器规则必须逐字节保持；阈值、排序、成本、仓位、退出规则不能借“修复”改变。实现错误修复后重建历史结果并标记版本，不覆盖旧证据。
仅研究和模拟；不接券商、不提交真实订单、不调整凭证或权限、不删除历史数据、不强制推送、不绕过安全拦截。
用户2026-10-30追加明确授权：连续推进，直到修复完成、合并上线。允许在最新代码审阅、必要测试及真实数据验收通过后，由GPT执行合并和上线核查，不必逐轮重复询问。未经真实验收不得称完成；此授权不包含实盘、凭证权限变更或修改冻结策略规则。
不得恢复已暂停的固定五股或600031研究。V7、BTC、ETF独立，不套用其资金或策略配置。
共享 Task01/Gold 数据采集及其调度由既有整合专项负责；本专项消费已验证快照并修复股东披露接入，不重复新增全量采集 cron。

## 每轮执行规则

1. 读取 main SHA、工作分支 SHA、相关 PR 完整差异和 CI；检查是否有重复任务或运行中计算。
2. 读取本队列、最近收据、用户新指令；优先处理泄漏、数据污染、冻结规则变动，其次 P1 数据/时点问题。
3. 一轮最多派发一个新实验和两个实现提交；网络/临时失败最多重试两次，同一确定性失败不得重复耗算力。
4. 使用 task_id + code_sha + source_sha256 + config_sha256 去重。没有真实 Run 和必要产物/Drive 回读不得标 VERIFIED_DONE。
5. 运行结果分别标明 CODE_WRITTEN、UNIT_TESTED、RUN_CONFIRMED、ARTIFACT_VERIFIED、DRIVE_READBACK_VERIFIED、RESEARCH_ACCEPTED；代码测试与策略有效性分开。
6. 合成数据只证明程序性质；真实历史结果、已看过的诊断、真实前向记录分开报告。失败保留，不改检验器迎合结果。
7. 更新 backlog、问题证据和下一步；只在新里程碑或新阻碍时简短通报，没有新证据不重复全量回测。
