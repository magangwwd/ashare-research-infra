# A股主板 AI 因子第一轮对照实验（V1）

状态：**独立研究试验；尚无真实样本外结果，不生成实盘或模拟交易指令。**

## 唯一问题

固定 LightGBM 模型与所有训练参数不变，新增三个预先冻结的AI候选因子，能否在严格样本外测试中改善 **5个完整交易时段的上涨概率预测**？

- A：现有因子（5/20/60日动量、20日波动率、20日量比）+ LightGBM。
- B：同一因子 + `path_efficiency_20d`、`volume_signed_pressure_10d`、`range_recovery_20d` + 相同LightGBM。
- C：20日动量简单排序，作为下一阶段组合收益回测基准；本版本不计算C组交易业绩。

这三个候选因子是GPT根据量价路径提出的可检验假设，**不是已验证的规律，也不是完整RD-Agent自动循环**。本轮不得边看测试结果边改因子、模型或阈值。

## 数据与隔离

1. 只从Task01 `data/current` 已验收Clean读取，不读取staging/Raw，不修改Task01、Gold或既有LightGBM Top3。
2. 使用 `research_engine.readiness` 核查三类核心数据最近连续 **>=750个交易日**。不满足时输出 `blocked_insufficient_contiguous_history`，进程返回非零。
3. 股票池使用历史主板 `security_master` 的 MAIN、沪深交易所、A_SHARE、上市/退市日期。退市证券不能因为今天已退市而从历史样本中消失。
4. 复权因子使用所在交易日的adj_factor，不以样本期终点的价格重算过去特征。
5. 在交易日t收盘后生成因子；标签以 **t+1日开盘买入、t+6日开盘卖出**的复权价格计算（持有5个交易时段）。缺少指定日期的开盘价时标记为无有效标签。
6. 历史ST、涨跌停、停复牌及PIT质量问题仍可能影响可交易性；模型统计不能直接视为投资收益。

## 对照规则

- 时间滚动：训练500个交易日、验证100、测试100，每次前进100个交易日。训练和验证末尾各隔离6个交易日，避免未来标签穿越到下一阶段。
- A、B严格使用相同的可用样本、训练标签、LightGBM超参数和固定随机种子，唯一差异为新增三个候选因子。
- 验证和测试报告同时计算Brier score（越低越好）及逐日截面RankIC（越高越好）。不根据测试集做特征选择、调参或反复挑选最优折。
- 注意：满足750连续交易日并不保证可形成多个测试折；如只有一个折，不能声称跨时期稳健。
- 本版没有执行策略资金曲线回测。A/B仅作预测能力筛选，暂不宣称扣费收益或交易优势。

## 第二阶段：交易收益独立验收

仅当B组在预先确定的跨折样本外检验中持续优于A组时，再建立与简单动量规则C组相同条件的组合回测：

- A股主板全历史股票池，一次最多持有一只，初始资金10万元，允许全部现金，每月最多新开仓2次。
- t收盘后选股，t+1开盘才能委托；按100股整数手、当日涨跌停与停牌等约束判断是否成交。
- 扣除佣金、卖出印花税、滑点及必要冲击成本，按历史日期适用税率，并处理卖出无法成交的顺延与持有现金的时段。
- 汇报净收益、最大回撤、买卖次数、空仓率、成交率、年度稳定性，并记录每次失败实验。

只有独立交易回测通过，才判断AI新因子有没有经济价值。

## 运行说明

研究环境另行安装 `lightgbm`，**不修改Task01根依赖**。必须先恢复或挂载Task01正式 `data/current`，随后执行：

```bash
python -m pip install lightgbm
python -m research_engine.ai_factor_pilot --root . --output metadata/ai_factor_pilot_v1.json
```

无正式数据/连续历史不足/其他错误时必须以失败状态退出并写入原因，不得用合成数据代替真实研究结果。第一版没有自动调度、GitHub Actions数据恢复、Drive写入、真实资金回测或自动策略上线。后续须在隔离分支新增验收后再扩展自动循环。
