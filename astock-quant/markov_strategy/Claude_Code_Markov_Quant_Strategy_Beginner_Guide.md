# Claude Code 复现 Markov 量化交易策略自学指南

> [!info] 视频来源
> [I Re-Created A Quant Trading Strategy With Claude Code (Insanely Cool)](https://www.youtube.com/watch?v=ZVMTeDBmSrI)  
> 频道：Lewis Jackson  
> 主题：把一个基于市场状态、Markov 转移矩阵、Hidden Markov Model 的量化交易框架，整理成 Claude Code 可执行的策略工作流。

> [!warning] 风险提示
> 这是一份学习笔记，不构成投资建议。视频里的方法更像“量化研究框架”，不是可以直接照抄赚钱的交易系统。真正使用前必须做数据清洗、交易成本、滑点、样本外测试、walk-forward 回测和小资金验证。

> [!summary] 一句话速懂
> 这套方法不是看 K 线形态猜涨跌，而是把市场分成“牛市、震荡、熊市”三种状态，再统计历史上这些状态如何互相切换，用概率决定下一步更偏多、偏空，还是观望。

---

## 0. 小白先看这张总图

```text
下载历史价格
  -> 计算最近 20 天涨跌幅
  -> 给每天贴标签：牛市 / 震荡 / 熊市
  -> 统计状态之间怎么切换
  -> 得到 3x3 转移概率矩阵
  -> 用今天的状态推测明天的状态概率
  -> 生成多空信号
  -> 做 walk-forward 回测
  -> 再用 Hidden Markov Model 优化状态识别
  -> 让 Claude Code 帮你实现、测试、封装
```

这不是“AI 预测明天价格”，而是：

> 用历史状态转移概率，估计市场更可能延续还是切换。

---

## 1. 普通交易者和量化交易的区别

视频开头的核心对比是：

| 普通交易者 | 量化思路 |
|---|---|
| 看趋势线、指标、形态 | 看数据、状态、概率 |
| 依靠主观判断 | 依靠规则和统计 |
| 容易受情绪影响 | 用系统约束决策 |
| 问“我感觉会不会涨” | 问“历史上这种状态后发生了什么” |

小白要理解：

```text
量化不是更神秘；
量化只是把判断标准写清楚，然后让数据反复检验。
```

---

## 2. 第一步：定义市场状态

视频用三种状态描述市场：

| 状态 | 英文 | 简单解释 |
|---|---|---|
| 牛市状态 | Bull State | 最近一段时间明显上涨 |
| 震荡状态 | Sideways State | 没有明显方向 |
| 熊市状态 | Bear State | 最近一段时间明显下跌 |

视频里的简化规则是：

```text
看最近 20 天总收益：

>= +5%  -> 牛市状态
<= -5%  -> 熊市状态
中间    -> 震荡状态
```

例子：

```text
最近 20 天总涨幅 = +8%
=> 今天标记为 Bull

最近 20 天总跌幅 = -7%
=> 今天标记为 Bear

最近 20 天总变化 = +2%
=> 今天标记为 Sideways
```

### 小白理解

这一步不是预测，而是分类。

就像给天气分类：

```text
晴天 / 阴天 / 雨天
```

市场也先分类：

```text
上涨环境 / 震荡环境 / 下跌环境
```

只有先知道当前环境，后面才知道应该用什么策略。

---

## 3. 第二步：给历史每一天贴标签

有了规则以后，就可以对历史数据逐日计算。

假设研究的是 Bitcoin：

```text
从第 20 天开始
每天都回看过去 20 天
计算这 20 天收益
然后给当天贴标签：
Bull / Sideways / Bear
```

最后你会得到一整条历史状态序列：

```text
Sideways -> Sideways -> Bull -> Bull -> Bull -> Sideways -> Bear -> ...
```

这条序列非常重要，因为后面所有概率都来自它。

---

## 4. 第三步：理解 Markov Property

视频提到 Markov Property，中文常叫“马尔可夫性质”。

小白可以这样理解：

> 明天更可能怎么走，主要取决于今天处于什么状态。

它不关心很久以前发生了什么，而是把重点放在“当前状态”。

例如：

```text
如果今天是 Bull
历史上明天继续 Bull 的概率是多少？

如果今天是 Bear
历史上明天转成 Sideways 的概率是多少？
```

这不是说历史更早的信息完全没用，而是这个模型为了简化，把问题变成：

```text
当前状态 -> 下一状态
```

---

## 5. 第四步：建立 3x3 转移矩阵

因为只有三种状态，所以明天也只有三种可能：

- Bull
- Sideways
- Bear

于是可以做一张 3x3 表：

| 今天 \ 明天 | Bull | Sideways | Bear |
|---|---:|---:|---:|
| Bull | ? | ? | ? |
| Sideways | ? | ? | ? |
| Bear | ? | ? | ? |

每一行加起来必须等于 100%，因为明天一定会落入其中一种状态。

例子：

| 今天 \ 明天 | Bull | Sideways | Bear |
|---|---:|---:|---:|
| Bull | 78% | 18% | 4% |
| Sideways | 25% | 55% | 20% |
| Bear | 6% | 24% | 70% |

### 怎么读这张表

如果今天是 Bull：

```text
明天继续 Bull 的概率 = 78%
明天变 Sideways 的概率 = 18%
明天变 Bear 的概率 = 4%
```

如果今天是 Bear：

```text
明天继续 Bear 的概率 = 70%
明天变 Sideways 的概率 = 24%
明天变 Bull 的概率 = 6%
```

这就是量化交易里常说的：

```text
不是预测确定答案，而是估计概率分布。
```

---

## 6. 第五步：看状态的“粘性”

视频里提到 stickiness score，可以理解为“状态粘性”。

它看的是矩阵对角线：

```text
Bull -> Bull
Sideways -> Sideways
Bear -> Bear
```

如果 Bull -> Bull 很高，说明上涨状态容易延续。  
如果 Bear -> Bear 很高，说明下跌状态容易延续。  
如果 Sideways -> Sideways 很高，说明震荡容易继续震荡。

小白理解：

```text
粘性越高，当前状态越不容易马上改变。
```

这也解释了“趋势是你的朋友”：

> 如果历史统计显示 Bull 状态大概率继续 Bull，那么在 Bull 状态下做多就更符合概率。

---

## 7. 第六步：多步预测

前面的矩阵回答的是：

```text
明天更可能是什么状态？
```

但如果想看 2 天、3 天、10 天以后呢？

量化上可以通过矩阵乘法来做：

```text
2 天后概率 = 矩阵平方
3 天后概率 = 矩阵三次方
28 天后概率 = 矩阵 28 次方
```

小白不需要手算，只要理解：

> 矩阵可以向未来滚动，估计多天后的状态概率。

### 重要限制

视频也提到，预测太远以后，概率可能会越来越接近一个稳定分布，信号会变弱。

这叫 stationary distribution，稳定分布。

小白理解：

```text
短期可能有信号；
拉得太远，概率会变得没那么有交易意义。
```

---

## 8. 第七步：把概率变成交易信号

视频里的简单信号思路是：

```text
信号强度 = Bull 概率 - Bear 概率
```

例子：

```text
明天 Bull 概率 = 65%
明天 Bear 概率 = 20%

信号 = 65% - 20% = +45%
```

这代表偏多。

如果：

```text
Bull 概率 = 18%
Bear 概率 = 60%

信号 = 18% - 60% = -42%
```

这代表偏空。

如果差距不大：

```text
Bull 概率 = 35%
Bear 概率 = 32%

信号 = +3%
```

这通常意味着信号很弱，可能不值得交易。

### 小白注意

信号不是仓位。

真正落地还要决定：

- 信号多强才交易？
- 每笔仓位多大？
- 什么时候退出？
- 是否允许做空？
- 是否扣除手续费和滑点？
- 连续亏损时是否降低仓位？

---

## 9. 第八步：walk-forward 回测

视频提到 walk-forward backtesting。

小白可以这样理解：

> 不要用未来数据训练过去的策略。

错误回测：

```text
拿 10 年数据一次性算出最佳参数
然后回头说这 10 年表现很好
```

问题是：你偷看了未来。

更合理的 walk-forward：

```text
用过去一段数据训练
  -> 在下一段未来数据测试
  -> 再向前滚动
  -> 重复很多次
```

例子：

```text
2015-2018 训练 -> 2019 测试
2016-2019 训练 -> 2020 测试
2017-2020 训练 -> 2021 测试
...
```

这样更接近真实交易，因为真实交易时你不知道未来。

---

## 10. 第九步：Hidden Markov Model

前面我们人为规定：

```text
20 天涨幅 >= +5% 是 Bull
20 天跌幅 <= -5% 是 Bear
中间是 Sideways
```

但这里有一个问题：

> +5% 和 -5% 是谁规定的？

这是人类主观设定。

Hidden Markov Model，简称 HMM，可以尝试让模型自己从数据中识别隐藏状态。

小白理解：

```text
普通 Markov：
我先告诉模型什么叫 Bull / Sideways / Bear。

Hidden Markov Model：
我不给标签，让模型自己从价格行为中找出几种隐藏市场状态。
```

视频里用一个生活类比：  
就像一个人进屋后看到一群孩子，一开始不知道每个孩子是什么性格，但观察一段时间后，会发现有的安静、有的活跃、有的容易失控。

市场也是这样：

```text
模型不一定先知道“牛市/熊市”的名字；
它先观察数据，再归纳出不同状态。
```

## 11. Claude Code 在这里做什么

Claude Code 的作用不是“替你保证赚钱”，而是帮你把研究流程自动化。

它可以帮助你：

- 写数据下载脚本
- 计算 20 日收益
- 给市场状态贴标签
- 生成 3x3 转移矩阵
- 计算状态粘性
- 生成信号
- 做 walk-forward 回测
- 尝试 Hidden Markov Model
- 生成报告
- 封装成可复用的 skill 或命令

视频里展示的思路是：

```text
把 Markov hedge fund method 写成 Claude Code skill
以后遇到一个新策略
就让 Claude Code 自动把这套状态/矩阵/回测框架套上去
```

## 12. Pine Script 在这里做什么

视频还提到 TradingView Pine Script。

它主要用于可视化：

- 当前状态
- 3x3 概率矩阵
- Bull / Sideways / Bear 的概率
- 图表上的状态变化

小白理解：

```text
Claude Code 负责研究和实现；
Pine Script 负责在图表上展示。
```

但要注意：

> 图表展示好看，不代表策略有效。有效性必须靠严格回测和实盘验证。

## 13. 一个小白可执行的学习路线

### 第 1 天：只理解状态

先不要写代码。

只记住：

```text
Bull = 最近明显上涨
Sideways = 最近没有方向
Bear = 最近明显下跌
```

练习：

找 BTC 或 SPY 的图，手动看最近 20 天是涨、跌，还是震荡。

### 第 2 天：理解转移矩阵

只看这张表：

| 今天 \ 明天 | Bull | Sideways | Bear |
|---|---:|---:|---:|
| Bull | 继续涨态 | 转震荡 | 转跌态 |
| Sideways | 转涨态 | 继续震荡 | 转跌态 |
| Bear | 转涨态 | 转震荡 | 继续跌态 |

练习：

用人话解释：

> 如果今天是 Bull，明天最可能是什么？

### 第 3 天：理解信号

记住公式：

```text
信号 = Bull 概率 - Bear 概率
```

练习：

如果 Bull=60%，Bear=25%，Sideways=15%，你偏多还是偏空？  
答案：偏多，因为 60 - 25 = +35。

### 第 4 天：理解回测

记住：

```text
不能偷看未来。
```

练习：

用纸写出：

```text
训练区间 -> 测试区间 -> 向前滚动
```

### 第 5 天：让 Claude Code 辅助实现

给 Claude Code 的任务不要写成：

```text
帮我做一个赚钱策略。
```

要写成：

```text
帮我实现一个研究框架：
1. 下载指定资产历史数据
2. 用过去 20 日收益定义 Bull/Sideways/Bear
3. 生成状态转移矩阵
4. 计算下一日 Bull、Sideways、Bear 概率
5. 用 Bull-Bear 概率差生成信号
6. 做 walk-forward 回测
7. 输出收益、回撤、胜率、交易次数、夏普比率
8. 扣除手续费和滑点
```

## 14. 关键术语速查

| 术语 | 中文 | 小白解释 |
|---|---|---|
| Quant | 量化交易者 | 用数学、数据、代码做交易研究的人 |
| State | 状态 | 市场当前属于上涨、震荡还是下跌 |
| Markov Property | 马尔可夫性质 | 下一步主要由当前状态决定 |
| Transition Matrix | 转移矩阵 | 统计状态之间切换概率的表 |
| Stickiness | 粘性 | 当前状态继续保持的概率 |
| Signal Generation | 信号生成 | 把概率转成多空信号 |
| Walk-forward Backtest | 滚动回测 | 只用过去训练，拿未来测试 |
| Stationary Distribution | 稳定分布 | 预测拉长后概率趋于稳定 |
| Hidden Markov Model | 隐马尔可夫模型 | 让模型自己识别隐藏市场状态 |
| Pine Script | TradingView 脚本 | 在图表上显示指标和信号 |

## 15. 我的理解

我对这个视频的理解是：

```text
它不是一个现成交易策略，
而是一个把“市场环境”数据化的研究框架。
```

它真正有价值的地方是：

1. 让你先判断市场状态，而不是直接预测价格。
2. 让你用历史转移概率说话，而不是靠感觉。
3. 让你把策略逻辑写成代码，方便测试和复盘。
4. 让 Claude Code 承担重复实现工作，而不是替你做最终判断。

但我也会保留一个重要怀疑：

> 视频把它包装成 “hedge fund method”，但小白不能因此默认它一定有效。

真正要验证它，至少要做这些事：

- 多资产测试：BTC、ETH、SPY、QQQ、个股分别测
- 多周期测试：日线、4 小时、1 小时分别测
- 参数稳定性：20 天、30 天、60 天回看期都测
- 阈值稳定性：+5/-5、+3/-3、+8/-8 都测
- 交易成本：手续费和滑点必须扣
- 样本外测试：不能只看历史拟合
- 极端行情测试：暴跌、暴涨、震荡期都要看

我的最终判断：

```text
这套方法适合作为“市场状态过滤器”，
不适合直接当成“无脑买卖信号”。
```

更稳的用法是：

```text
原有策略
  + Markov 状态过滤
  + walk-forward 回测
  + 风险控制
```

例如：

```text
如果原策略发出做多信号，
但 Markov 状态显示 Bear 粘性很强，
那就降低仓位或跳过。

如果原策略发出做多信号，
且 Markov 状态显示 Bull 延续概率高，
那才考虑正常执行。
```

## 18. 一句话总结

这套 Claude Code + Markov 量化框架的核心，是把市场环境从“我感觉现在很强/很弱”改成“历史数据显示当前状态下一步更可能如何转移”，但它必须经过严谨回测和风控，不能直接当成赚钱机器。
