# A股主板3–5日短线：单只股票、固定金额、全进全出（独立研究版）

- 策略ID：`MAINBOARD_SWING_3TO5_FIXED_CNY_PAPER_V1`
- 初次建档：2026-10-20
- 状态：`PAPER_ONLY_NO_BROKER_NO_LIVE_AUTHORIZATION`
- 独立于冻结的 `LOCK_MARKUP_SINGLE_PAPER_V1` 及R1五股策略；不修改原策略，也不启用实盘接口或新的定时任务。

## 策略约束

| 维度 | 机器规则 |
|---|---|
| 股票池 | 沪市600/601/603/605及深市000/001/002/003开头的普通A股；历史ST、风险警示、名称状态不明均排除 |
| 同时持股 | 一次仅一只；持有时忽略其它新信号，不在同一日卖出后立即换股 |
| 交易金额 | 每单默认买入预算40,000元；允许设为30,000–50,000元，不根据账户权益百分比计算仓位 |
| 交易方式 | 按100股整手一次建仓；退出时一次卖出全部股票；不补仓、不加仓、不融资 |
| 初始现金 | 模拟账户50,000元，实际股票买入金额按手数向下取整，剩余保留现金 |
| 持有期 | 买入日为第1日；第3日起达到目标收益可卖；第5日收盘退出。止损可从第2日提前卖出；买入日不卖出 |
| 初始风控 | -3%止损，+5%目标止盈；同日触及两者按止损优先，若跳空跌破止损按实际开盘基准加滑点 |
| 成交限制 | 下一交易日核验历史ST、涨跌停和停牌，不可买则跳过；连续涨停不假设买到，封死跌停不假设卖掉，允许持仓被迫超过5日 |

固定预算不是“账户资金满仓”。若因股价与整手交易单位不能成交3万元以上，则放弃，不默默缩小为百分比仓位。模拟中全进全出仅表示模型不做分批买卖，**不保证券商真实订单全额成交**。

## 选股信号

1. 每个交易日收盘后，计算复权收盘价、20日均线与60日均线；20日均线大于60日均线。
2. 当日复权收盘价严格突破**前20个交易日**复权收盘最高价，不能把当日高价或明天的数据当作历史。
3. 今日成交量不低于此前5日日均成交量1.2倍、此前20日日均成交额至少1亿元、当日收阳。
4. 主板至少500只具有20日均线，其中至少45%收盘站上20日均线，否则不新开仓。
5. 按突破幅度和量比构成确定性分数排序，代码打破平分；历史ST名称可得且正常才进入候选。
6. 信号产生于当日收盘，最早下一交易日开盘模拟买入；与信号日同复权尺度比较，高开超过2%取消追入。

## 风控和成本

- T+1：买入当天日内跌破止损，次个允许卖出日开盘才模拟卖出，不虚构同日可卖。
- 停牌、跌停封板、风险字段缺失：未能执行的退出延后，可能超期且超过3%亏损，必须留异常日志。
- 假设佣金万3（最低5元/笔），过户费万0.1（两边），卖出印花税万5，买卖各0.1%的价格滑点。券商真实费率可能不同。
- 历史资料回测默认自2024年起；公司行动以复权因子做总收益**近似代理**，不等于经过逐次送转分红与到账现金核对的真实账户净值。标记含除权代理交易。
- 日线OHLC回测不能复原盘中止盈/止损的先后顺序及撮合盘口；这是研究性假设而非真实可成交记录。
- 交易所规则和印花税依据：上海证券交易所、深圳证券交易所2026年修订交易规则，以及财政部税务总局公告2023年第39号。

## 本地检验

在 `astock-quant/stock_state_strategy` 目录执行：

```bash
python -m unittest -v test_short_swing_3to5_v1.py
python short_swing_3to5_v1.py \
  --market-root /path/to/down_data/data/gold/main_board \
  --risk-root /path/to/risk_data \
  --start 2024-01-01 --end 2026-10-19 \
  --cash-cny 50000 --budget-cny 40000 \
  --output /tmp/short_swing_result.json
```

Gold输入：`manifest.json`、`daily_prices/year=YYYY/month=MM/data.parquet`、`adjustment_factors/year=YYYY/month=MM/data.parquet`。PIT输入：`daily_limits/`、`suspension_events/` 和 `name_history/data.parquet`。所有历史成交都由真实历史日线的可得字段推算，不接受父仓库的旧Yahoo CSV作为正式主板行情。

GitHub Actions：`.github/workflows/short-swing-3to5-paper.yml`。PR只做离线单元测试；经代码审查合并到主分支后可手工 `workflow_dispatch` 触发真实Gold回测；**不添加schedule**。临时Runner用既有`GDRIVE_RCLONE_CONFIG_B64`读取Google Drive，结果保存为不可覆盖的

`gdrive:stock_state_strategy/output/short_swing_3to5_v1/<end-date>/run_<github-run-id>/result.json`

上传以后需执行 `rclone check`，缺数据/无授权必须报错，不得产出虚构成功报告。

## 验收

第一阶段至少检查：T+1、只持有一只、买入100股整手、金额3–5万元、全数卖出、止损优先、止盈不早于第三天、五日超时、封死跌停延期、未知ST/涨跌停拒绝、未平仓不得强制算作盈利。

第二阶段从真实Gold运行历史回测，报告笔数、成本后收益、胜率、最大回撤、数据期间、异常和复权代理笔数。第三阶段冻结版本后新交易日开始前向纸面观察至少30笔，不根据同一批历史过度调参；验证之前不连接券商也不承诺收益。
