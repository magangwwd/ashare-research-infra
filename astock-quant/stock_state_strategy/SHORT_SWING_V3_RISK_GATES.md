# 3–5日主板短线：V3状态式风险闸门研究

## 原则
本研究运行于 `magangwwd/ashare-research-infra` PR #76 的草稿分支，仅纸面回测，不自动交易、不新增定时任务、不合并。固定规则：同一时间最多一股、初始现金5万元、计划每次买入4万元且实际单次投入不少于3万元且不超过5万元、100股整数手、买入后原则上3–5个交易日、因中国T+1、停牌或止损可以提前或延迟。**禁止改动V1/V2原始回测存档。**

## 和V1/V2的关系
原V1 `short_swing_3to5_v1.py` 是执行/费用/T+1和涨跌停的统一模拟器；V2 `short_swing_3to5_v2_research.py` 的 `BALANCED` / `LOOSE` 分别是日线预选信号，本研究保持不变。V3 `short_swing_3to5_v3_research.py` 在V1的**新开仓**路径上叠加状态风控：绝不对平仓路径设门槛，绝不改变既定买入金额、交易价格和止损/止盈执行。研究启动时从源代码核对完整V1 Git blob SHA，并为每个候选组合逐项比较不加风控的模拟输出和V1的成交记录、订单、净值曲线、异常明细。

## 预声明比较组
两个基础策略分别研究下述五种配置，共10种结果：

| 方案 | 何时暂停新开仓 | 恢复条件 |
|---|---|---|
| NO_GATE_REPRODUCED_V2 | 不增加限制 | 不适用 |
| LOSS2_COOLDOWN_10 | 已**完成**的连续2笔交易亏损 | 暂停后10个交易日，到第11个交易日允许新开仓 |
| DD_HALT_18 | 平仓后现金相对此前净值峰值跌18%或以上 | 本次研究区间不再新增持仓 |
| DD_HALT_22 | 同上，阈值22% | 同上 |
| DD18_AND_LOSS2 | 两项同时生效 | 达到18%阈值即永久停止开新仓 |

亏损判断只看交易完成后当时已知的净利润。回撤闸门在**空仓**、下一次有候选信号时执行；不会为了维持回撤约束而阻挡卖出。回撤触发线**不是最大回撤上限**，盘中浮亏、T+1和跳空可能导致真实最大回撤超过25%。

## 验收项
1. 原V1、V2、15分钟单股影子审计及V3合成对抗测试通过；原V1执行源 SHA 必须准确匹配，否则拒绝运行。
2. 使用真实Google Drive `down_data/data/gold/main_board` 历史Gold与PIT名称、停复牌、涨跌停记录，缺失即报错，不降级为模拟行情。
3. V3在同组信号无风控时与V1对照结果完全相同；每个版本输出成本后收益、最大回撤、交易笔数、逐日净值、事件以及完整交易清单。
4. 历史对照的筛选和风控参数已经预先固定，不以同一历史表现自动选出实盘参数；2024–2026已观察历史数据不得冒称独立样本外验证。
5. 无法由1只股票15分钟线验证全主板的盘中可成交性，订单簿/分钟线不足处如实披露。

## 可运行性
GitHub Actions `.github/workflows/short-swing-3to5-v3-research.yml` 仅研究，开发分支的PR受控触发、workflow_dispatch可重复手动运行；没有 schedule。输出 Google Drive `stock_state_strategy/output/short_swing_3to5_v3_research/YYYY-MM-DD/run_ACTION_ID/comparison.json`，`rclone check`核验数据。

## 风险合格条件
研究阶段优先比较正收益、最大回撤低于25%、跨年度表现一致性、成交数量和费用；这不是对投资者的最大亏损承诺。即使历史达到阈值，仍需在冻结规则后进行未来行情纸面交易观察，才可重新讨论是否进一步进入实盘流程。
