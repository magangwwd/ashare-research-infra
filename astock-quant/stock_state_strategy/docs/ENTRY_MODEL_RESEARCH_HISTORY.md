## 1. 目标与当前结论

系统最终只向选股和入场层输出一个核心指标：

```text
FinalCPRR = 预测所选交易周期内的可执行盈亏比
```

它同时用于同日排序和绝对入场门槛。分数不足时必须空仓，不强制每天交易。

当前状态：V1、V2均未通过，不能进入模拟盘或实盘。工程链路已经跑通，下一版只研究面向散户和小资金的“单股票Top1”方向。

## 3. 已确认的问题

### 3.1 峰值标签不等于可交易收益

`demo/stage1_bull_signal` 的Model A能预测“未来20日是否触及+20%”，但候选终值收益中位数弱，完整交易回测长期亏损。高Lift只能证明模型学会了峰值事件，不能证明买入后赚钱。

### 3.2 stage1比值模型不能直接复用

`ratio_label.py` 的MFE/MAE比值方向合理，但现有实现存在期限漂移、正式入口和报告缺失、Model B函数签名不一致、文档参数与代码默认值不一致等问题。2025—2026也已被反复用于研究，不能再视为真盲测。

### 3.3 V2学成了市场状态，不是个股排序

| 特征 | V2平均增益占比 |
|---|---:|
| 市场20日收益中位数 | 56.61% |
| 市场宽度 | 34.40% |
| 其余17个个股特征合计 | 8.99% |

两个市场特征占约91%，但它们在同一天对所有股票几乎相同，不能解决“今天哪只股票最好”。V2测试期日截面Rank IC只有0.014，低于0.03要求。

## 4. 可继续复用的基础设施

V2已经实现并核验：

- T日收盘产生信号，T+1开盘可执行入场；
- MFE只使用买入后允许卖出的交易日；

## 5. Top1小资金策略规范

策略暂定名：`Top1-CPRR Small`。

适用范围：约10万至100万元的非融资研究账户。超过100万元需要重新验证成交冲击和容量。当前规范是待回测方案，不是实盘建议。

### 5.1 核心交易约束

```text
同一时间最多持有1只股票
每天最多产生1只Top1候选
已有持仓时不买新股票
不加仓、不补仓、不减仓
一次性买入计划股数，退出时一次性全部卖出
不融资、不加杠杆
```

“全进全出”指对开仓时计算好的目标仓位一次买齐、一次卖清，不自动等于把账户100%资金押在一只股票上。账户投入比例仍由冻结的单笔风险和仓位上限决定。

持仓期间出现的新Top1只记录为“因已有持仓跳过”，不能换股，也不能事后选择性补交易。回测必须同时报告这些被跳过信号的结果，检查持仓占用造成的时序选择偏差。

### 5.2 股票池

每个T日收盘后只保留：

- 沪深A股主板；
- T日真实非ST/*ST；
- 上市至少250个交易日；
- 20日平均成交额至少1亿元；
- 价格、复权、成交额和涨跌停状态质量合格；
- 不处于停牌或明确无法正常成交状态。

历史ST和停复牌时点数据目前不完整，补齐前只能做研究回测。

### 5.3 预测周期不固定为20日

V3同时建立以下预注册周期：

```text
H = 20、30、40、60个交易日
```

每个周期分别生成可执行标签：T+1开盘入场，计算未来H个可卖交易日的MFE、峰值前MAE、费用后CPRR和到期净收益。每个H训练独立的横截面Ranker。

周期选择只允许使用2022、2023、2024滚动验证：

1. 训练至2021、验证2022；
2. 训练至2022、验证2023；
3. 训练至2023、验证2024；
4. 比较H=20/30/40/60的Rank IC、Top1实际CPRR、费用后收益、盈利因子和回撤；
5. 在满足最低交易数和风险标准的周期中，选择跨年度中位表现最好的H；
6. 选定周期后冻结，不得用2025—2026重新挑周期。

当前历史线索显示40日值得作为候选，但stage1的40日结果不能一键复现，也没有稳定盈利，因此不能直接宣布40日最优，必须按上述统一流程重跑。

若四个周期都不满足验收标准，则停止Top1方向，不强行选择一个“相对最好但仍亏损”的周期。

### 5.4 个股排序模型

使用LightGBM LambdaRank，按 `signal_date` 分组训练：

```text
训练目标：同一日候选股票的实际CPRR横截面等级
最终输出：FinalCPRR_V3
同日选择：FinalCPRR_V3最高的1只
```

要求：

- Ranker不使用市场收益、市场宽度等同日共同特征；
- 使用个股趋势、相对强度、位置、波动、量价和流动性特征；
- 行业和市值尽量横截面中性化；
- 5个时间偏移模型组成集成；
- 只有Top1分数达到冻结绝对门槛且模型分歧不过大时才入场；
- 不达标时保持现金，不使用第2名替补。

市场状态若以后使用，只能作为独立的“允许/禁止开仓”模块。此前市场regime过滤器样本外失败，V3第一版默认关闭。

### 5.5 入场

1. T日收盘后计算候选和Top1；
2. 账户无持仓且信号过绝对门槛时，安排T+1买入；
3. T+1以开盘附近限价一次性买入目标股数；
4. 一字涨停、停牌或相对T日收盘高开超过3%时取消，不追价；
5. 取消后当天不使用第2名替补；
6. 持仓结束前不接受任何新开仓。

绝对阈值不能沿用V2的1.5，因为该阈值在测试期每天都通过，没有空仓作用。V3阈值只能在2022—2024滚动验证中确定，目标是低频等待，而不是每天强制交易。

### 5.6 仓位与全进全出

研究默认：

```text
同时持仓数 = 1
单笔账户计划风险上限 = 当前权益的1%
单只股票名义仓位上限 = 当前权益的25%
现金不足时不交易
按100股整数手一次买入
任何退出条件触发后一次卖出全部持仓
```

目标仓位：

```text
有效风险比例 = max(冻结保护止损距离, 0.5×ATR20, 预测MAE风险下限)
目标仓位 = min(权益×25%, 权益×1% / 有效风险比例)
```

这意味着全进全出的是“目标仓位”，不是默认100%满仓。若要研究100%资金单股满仓，必须作为单独高风险方案重新授权和回测，不能默认采用。

### 5.7 退出

所有退出均一次性清仓，不允许分批止盈或减仓。

每个候选周期H使用同一套预注册执行框架：

- 买入当日不卖出，遵守T+1；
- 正常可卖时触发保护止损，整仓退出；
- 浮盈达到冻结启动点后，触发移动止盈时整仓退出；
- 未提前退出则在第H个交易日整仓到期退出；
- 跌停无法成交时顺延，保留真实尾部亏损；
- 不补仓、不摊低成本、不部分落袋。

保护止损、移动止盈启动点和回撤幅度先固定一套开发参数，不能与H一起做大规模联合网格搜索。若必须比较参数，只能使用嵌套滚动验证，并对多重比较作惩罚；最终只保留一套冻结规则。

## 6. 验收标准

开发阶段只使用2022—2024滚动验证。选定周期和模型至少满足：

- 日截面Rank IC平均值≥0.03，且至少2/3年度为正；
- Top1实际CPRR均值和中位数至少2/3年度高于全候选；
- Top1到期净收益均值和中位数至少2/3年度高于全候选；
- 单股票顺序回测完成交易不少于100笔；
- 平均R>0.15；
- 盈利因子>1.20；
- 最大回撤不超过15%；
- 收益超过同一可用资金日期的配对随机Top1中位数，并争取超过随机75分位；
- 不能由单只股票、单个月份或少数尾部赢家贡献大部分利润。

单股票模式的随机对照必须遵守相同规则：只在策略空仓并准备入场的日期随机抽1只，持有期间同样不能开新仓。不能拿“每天都能买”的随机组合与“持仓时跳过信号”的策略直接比较。

通过开发标准后冻结代码、周期H、模型、阈值、仓位和退出规则。真正前向观察从2026-08-11以后新增数据开始，至少观察12个月或完成100笔交易，以较晚者为准。

## 12. 严格a/b目标与E1快速回测设计（2026-08-16）

### 12.1 机器学习目标

T日收盘生成信号，T+1开盘价为计划买入价 `P0`。针对H=20/30/40分别生成标签：

```text
a_H = max(T+2至T+H+1复权最高价 / P0 - 1, 0)
b_H = max(1 - T+1至T+H+1复权最低价 / P0, 0)
ActualRatio_H = a_H / max(b_H, 1%)
```

`a`只使用买入后可卖交易日的最高价，避免把A股买入当日无法卖出的高点当成可实现收益；`b`从买入日开始计算，因为风险在买入当日已经发生。原始a、b和比值均保留；1%只用于防止b接近0造成数值爆炸。

不直接回归比值。使用两个LightGBM分位数模型：

```text
PredA50 = 未来上涨空间a的条件中位数
PredB75 = 未来下跌风险b的条件75%分位数
FinalScore = PredA50 / max(PredB75, 1%)
```

`FinalScore`是唯一选股和入场排序指标。每日只取Top1；Top1未达到开发集冻结的绝对阈值时空仓，不能用第2名替补。

### 12.2 预测输入

首版继续使用17个T日时点特征：5/20/60日收益，股价相对MA20/MA60，MA20相对MA60，距20/60日高点，ATR14比例，20日波动率，5/20日波动率比，成交量/成交额/换手率相对20日均值，是否接近20日高点，以及20/60日相对强弱排名。

LightGBM不做统一Min-Max或Z-score。仅清理无穷值、对训练折内长尾异常值保持审计；所有处理只能由当时训练区间确定，不能使用全样本统计量。此前净R特征审计不适用于严格a/b标签，不能沿用其候选结论。

### 12.3 E1全进全出

买入时冻结PredA50和PredB75：

```text
StopPct = max(4%, PredB75, 1.5×ATR20)
TargetPct = 0.8×PredA50
```

始终只持有一只股票；一次性买入开仓时计算的目标股数，一次性全部卖清；不加仓、不补仓、不减仓、不换股。目标仓位继续采用单笔风险1%、仓位上限25%和100股整手，不等同于账户100%满仓。
