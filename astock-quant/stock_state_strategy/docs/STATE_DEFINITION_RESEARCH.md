# 单支股票状态定义池与转换回测结论

更新日期：2026-08-18。行情截止：2026-08-11。

## 最终结论

本轮已经完成“先判断是否适合定义，再判断吸筹/锁仓/拉升/派发”的日级系统。

- 当前3,193只在市主板股票中，159只进入A级高可信候选，246只进入B级观察池，2,788只删除；
- A级中151只是拉升、8只是锁仓；
- A级表示状态证据质量较高，不表示未来上涨概率达到80%，也不表示可以买入；
- 日级历史回测中，静态A级、锁仓转拉升以及与Demo01特征的联合规则均未通过预先冻结的策略门槛；
- 因此当前状态池可用于诊断、监控和风险提示，不能授权自动入场。

程序最终决策码：`NO_ENTRY_AUTHORIZATION`。

## 冻结准入规则

- 上市不少于250个交易日；
- 近250日有效行情不少于238日，近20日有效成交不少于18日；
- 近20日日均成交额低于3,000万元删除，低于1亿元不能进入A级；
- 近20日一字涨跌停不超过3日，排除历史ST或风险警示；
- 股东人数和前十大流通股东至少各有两次更新，最新公告不超过180天；
- 最高状态分不低于65，领先第二状态不少于10分，指标覆盖不低于80%；
- 最近5个交易日至少3日指向同一状态；
- A级可信度不低于80，B级不低于65。

`down_data`没有逐日大/小单资金流。吸筹和派发缺少独立资金证据，因此可信度封顶79，只能进入B级。大单分类按订单金额，不等同于机构或同一控制人账户。

## 严格可执行回测

日级状态缓存包含2022-01-04至2026-08-11共3,534,674条记录、3,345只股票。收益使用Demo01 V5标签：信号日收盘后产生信号，T+1开盘成交，包含双边费用、精确涨跌停、历史ST、停牌、ATR止损和延期退出。

预先冻结的通过标准为：2023—2024开发期和2025—2026历史诊断期都不少于30笔、平均净R为正、利润因子不低于1.2、相对同日可交易股票的净R增量为正且HAC `p<0.05`。

方向虽然为正，但均不显著，而且开发期绝对收益、平均净R和利润因子均未通过。

## 与Demo01特征的关系

2,419条可匹配的锁仓转拉升记录，其Demo01冻结收益特征百分位最高仅为87.31%，没有一条达到Top10%。估计盈亏比均低于1，最大仅0.9135，估计期望全部为负。

这说明两套逻辑存在结构冲突：

- 锁仓转拉升强调突破、趋势和成交活跃；
- Demo01当前冻结收益组合偏好低换手、低成交量和低波动；
- 因此“锁仓转拉升＋Demo01收益Top10”与严格盈亏比1.2规则都产生0个候选。

单持仓诊断只交易锁仓转拉升时共有61笔，总收益+3.28%、利润因子1.177、最大已平仓回撤-7.77%，但逐年方向反转：2023、2024为正，2025、2026为负，仍不达标。

## 派发风险

“任意状态转派发”的同日相对净R在两段均为负：

- 2023—2024：`-0.0071R`，`p=0.8774`；
- 2025—2026：`-0.1054R`，`p=0.0203`，尾部损失同时显著增加。

它在后段有风险提示价值，但开发期不显著，逐年也会反转。因此目前只显示预警，不自动卖出。

## 可落地用途

当前可安全落地的是监控系统，而不是交易系统：

1. 每日生成A级、B级、删除池及逐股原因；
2. A级锁仓进入观察，A级拉升标记趋势状态；
3. 锁仓转拉升只记录为前向候选，不开仓；
4. 转派发显示风险预警，不强制卖出；
5. 从2026-08-11之后积累完全只读的前向样本，不再调整本版阈值。

如果后续补齐逐日L2资金流，应先独立验证资金流是否提高吸筹/派发的阶段区分和未来风险预测，再决定是否解除79分上限。不能把大单、特大单直接等同于机构资金。
