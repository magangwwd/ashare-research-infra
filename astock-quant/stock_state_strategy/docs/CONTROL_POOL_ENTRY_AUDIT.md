# V6：控盘Top20监控池与V5特征盈亏比组合审计

更新日期：2026-08-18。行情截至2026-08-11。

## 结论

**控盘Top20监控池不能作为当前demo01的入场条件。**

严格的特征盈亏比规则没有产生任何交易：V5冻结特征中，没有候选同时满足同日收益组合
Top10%、历史估计盈亏比不低于1.2和估计期望R为正。增加控盘Top20条件不能改善零入场规则。

为避免把零交易误当成风控有效，另外做了不改变特征方向的分解审计。无论只使用收益Top10，
还是同时要求收益与尾部安全双Top10，控盘Top20过滤都降低了盈亏质量。

## 固定规则

- 控盘池：demo02冻结行为评分在同公告日Top20%；公告日起可用于次日入场；
  下一次有效公告低于Top20即移出，最长保留120日；公告日横截面至少20只。
- 收益特征：V5冻结的5项净R特征，方向和权重不变。
- 尾部风险：V5冻结的8项尾部风险特征，方向和权重不变。
- 盈亏比：只使用当时之前且留出45日标签成熟期的数据，以收益/安全组合十分位估计
  盈利R和亏损R；要求估计盈亏比≥1.2、期望R>0且收益组合为同日Top10%。
- 执行标签：T日信号、T+1可执行开盘入场，ATR裁剪止损，20日或首个可卖日退出，
  包含费用、停牌、历史ST和一字跌停延期。

## 解释

demo02的高控盘评分识别的是股东集中、换手和波动收缩、低派发风险等“锁筹式状态”，
并不表示存在正向价格催化。它与demo01的低成交、低换手、低波动特征还有明显信息重叠，
交集会进一步集中到缺少买盘推动的股票，历史结果因此变差。

本轮2025—2026数据已被两个项目此前查看，只能称历史诊断。结论是不把控盘Top20加入
当前入场规则；若将来获得大单持续流入或Level-2订单失衡等独立方向信息，应另立版本，
并从2026-08-12以后做只读前向验证。
