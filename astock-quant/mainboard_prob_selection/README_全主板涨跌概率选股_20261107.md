## 2. 方案要点

1. **两个概率，分工明确。**
   - `p_rel` = P(本周跑赢全池中位数)，用于选股排序。
   - `p_abs` = P(本周上涨)，用于决定是否空仓：首选股的 p_abs < 0.5 就空仓。

   上一轮用单一的绝对涨跌概率去排序，这个概率主要反映大盘方向，在个股之间几乎没有区分度。
2. **特征不含股票身份。** 33个个股特征（动量、反转、波动、换手、市值、估值、20日涨跌停次数、缺口、上市年龄等）每周做截面百分位，另加7个市场状态特征。去掉身份哑变量，避免模型在全量样本上记住历史。
3. **股票池按信号日判断。** 剔除ST；上市满120个交易日；20日日均成交额 ≥ 2000万；股价 ≥ 2元；当日停牌的剔除。每周约2,300只合格。
4. **模型。** LightGBM 面板模型，2015年起扩展窗口，**按季度重训**（28次）。只用 exit_date 早于预测期的样本训练，防止标签泄漏。另用逻辑回归做对照。
5. **成交。** 周二开盘一字涨停买不进，顺延到排名第2～3的股票；遵守 T+1；退出价在跌停价时卖不出，顺延到下一交易日；印花税2023-08-28起减半；佣金万2.5、最低5元；单边滑点0.1%。
6. **效率。** 日线只读一次，生成周度面板缓存（153万行，约2分钟）；训练13分钟；14个账户加400次随机对照共20秒。之后改参数只需重跑第3、4步。

## 4. 结论

1. **全主板选股可以做，关键是改对目标。** 用相对概率排序、绝对概率择时、去掉身份变量之后，全量版从上一轮的 −11%～−13% 改善到 J 的 +28%，并跑赢96%的随机对照。
2. **目前仍不建议实盘。**
   - 单笔 t 值只有 0.98，统计上不显著。
   - 对费用（×2时仅剩 +7%）、退出时点（开盘退出约0%）、模型选择（逻辑回归转亏）都很敏感。
   - H 和 J 是看到 A 的止损结果之后才加的变体，存在事后挑选偏差。
3. **在原规则（1%计划风险）下，收益空间很小。** 每周换仓加上10%～15%的仓位，年化不到1%。真正的约束是“周频单股换仓 + 成本”，而不是模型。
4. **信号最可靠的用途是排除。** 最低十分位每周 −0.66%，比最高十分位的正超额强得多。

## 5. 建议的下一步（按性价比排序）

1. **把模型当过滤器用。** 原32股池或任何人工选股，先剔除全主板 p_rel 后30%～50%的票，再按原有规则交易。成本几乎不增加。
2. **降低换手。** 把标签改为2周或4周，按相同的重训和成本框架重跑。本轮的“周二续持前10%”变体效果不好，已舍弃。
3. **选定一个版本后冻结，做前向纸面跟踪。** 冻结 J 或过滤器版本（不再调参），从2026-11-10那一周起记录每周信号，3～6个月后用真实前向数据验收。
4. **核验分红现金流。** 目前收益用复权因子近似分红，这部分尚未核验。

**结论**
1. **ChatGPT 的8%保护规则和全主板排序可以叠加**：剔除高波动股后，收益、t 值和对费用的承受力都比全池版更好。这条规则是事先就定好的，不是这次从数据里挑出来的，事后挑选的偏差较小。
2. **延长持有期在单股账户上没有用**：IC 随持有期上升，但 Top1 的超额不显著，2周版亏损。不再继续这个方向。
3. **过滤器的价值很稳定**：剔除后50%之后，随机选股从 −22% 提升到 −6%（全池、50%预算）。
4. **在1%计划风险下，扣费后几乎为零**：要不要采用，取决于是否允许单笔仓位放到50%（该版本 V0 单笔最差约亏交易前净值的4.6%；最终 V7 为 **8.22%**，见勘误）。
5. **候选冻结版本**：全主板 + 保护池（2ATR ≤ 8%）+ LightGBM `p_rel` 排序 + `p_abs` ≥ 0.5 择时 + 周二开盘买、周五收盘卖 + 50%预算、周内不止损。累计测试了约30个变体，t=2.45 的单侧 p≈0.0074，按30次做 Bonferroni 校正后约为 **0.22，不显著**（原文“处在显著边缘”的说法有误，见勘误）。**必须先做前瞻纸面验证**。

## 8. 模型与规则说明（问答整理，2026-11-07）

### 8.1 交易节奏
- **选股**：用周二前一个交易日的收盘数据，通常是周一收盘；周一休市时用上周五收盘。周二0点前完成。
- **买入**：周二开盘价买入，滑点0.1%。周二休市的那一周直接跳过，不顺延。首选股开盘一字涨停或停牌时，依次改买第2、第3名。
- **卖出**：当周最后一个交易日收盘卖出，通常是周五；周五休市时提前到当周最后一个交易日。卖出价在跌停价时卖不出，顺延到下一交易日，先试开盘、再试收盘。顺延期间不买新股票。
- **约束**：T+1；每次最多持一只；可以空仓。

### 8.2 选哪一只
- 股票池：非ST、上市满120个交易日、20日日均成交额 ≥ 2000万、股价 ≥ 2元、选股日未停牌，再剔除 2ATR14 > 8% 的股票（保护池，ChatGPT S1 的规则）。每周约剩1,400只。
- **按 `p_rel`（本周涨幅跑赢池内中位数的概率）从高到低排序，取第一名。** 不是按上涨概率（V3 = −14.6%）排，也不是按预测涨幅（V6 = +21.2%）排。
- 择时：首选股的 `p_abs`（本周上涨概率）≥ 0.5 才买，否则空仓。

### 8.3 V7 模型的组成
- 3个 LightGBM 二分类模型，参数相同，随机种子分别是 20261107、20261108、20261109。各自预测 `p_rel`，取平均后排序。另有1个 LightGBM 预测 `p_abs` 用于择时。
- 参数：300棵树，学习率0.03，31个叶子，每个叶子至少2000个样本，每棵树抽70%的样本和70%的特征，L2正则10。
- 为什么有效：行列抽样使单个模型对排名靠前股票的判断带有偶然性，单股账户对此很敏感，3个模型取平均可以降低这种噪声。V7 不包含新的规律。
- 特征共40个：33个个股截面百分位特征（动量、反转、波动、换手、量比、市值、估值、涨跌停次数、跳空、上市年龄），加7个市场状态特征。不含股票代码。
- 训练样本用全部合格股票，不只用保护池（只用保护池训练的 V5 更差）。选股时才限定在保护池内。

### 8.4 训练窗口与重训频率
- 窗口：从2015-01开始的扩展窗口，之后只加不删。每次重训只用 exit_date 早于预测期第一周的已结算周。起点和窗口类型都是事先定的，**没有比较过其他起点，也没有比较过滚动窗口**。
- 回测：每季度初重训，共28次，训练集从约60万行增长到139万行。选季度是为了效率；**按月重训的对照已经中止，没有结果**。
- ⚠️ 前瞻脚本 `09_weekly_signal.py` 目前**每周都重训**，和回测的季度重训不一致。建议改成季度重训并缓存模型（待确认）。

### 8.5 与 ChatGPT 对话“研究股票涨跌概率”的对照（读取了昨天20:15以后的内容，更早的消息页面加载失败）
- ChatGPT 的模型：共同逻辑回归，32只股票（围绕603580艾艾精工挑选）；预测“周二买、周五卖，扣费后是否盈利”的概率（绝对概率），> 50% 才买；特征是涨跌、波动、均线距离、量额变化、收盘位置，加全主板的市场涨跌和广度；按月重训。全量版另外加了股票身份稀疏编码。
- 保护距离 = max(2ATR14, 2%)，> 8% 不买；按计划风险1%计算仓位（S1设计）。
- 结果：32股周二到周五版本，收盘卖 +19%、开盘卖 +23%；新协议重训后 +5.8% 到 +6.8%；全量训练全量选股 −11% 到 −13%。11-10起已在 ChatGPT 侧运行32股前瞻纸面模拟（周二0点预测）。
- 在已读到的部分里，**没有看到“逻辑回归优于 LightGBM”的验证**。在本项目的全主板数据上，LightGBM 优于逻辑回归（IC 0.104 对 0.091）。
